증강체 칼바람 매니저 V10

이번 버전은 칼바람 전투 엔진 V2를 추가했습니다.

실행:
- index.html을 브라우저에서 열어도 됩니다.
- 기존 GitHub Pages에 업로드하면 그대로 동작합니다.

추가된 전투 요소:
- 제공된 칼바람 맵 이미지를 전투 배경으로 사용
- 넥서스 → 쌍둥이 포탑 2개 → 억제기 → 2차 포탑 → 1차 포탑 구조
- 단일 공격로
- 중앙/측면 수풀 표시
- 4개의 회복 유물
- 시작 레벨 3 / 시작 골드 1400
- 초당 6골드 / 자동 경험치
- 본진 밖 아이템 구매 제한을 시뮬레이션하는 상태 표시
- 귀환/본진 회복 없음
- 억제기 파괴 후 슈퍼 미니언 웨이브
- 35분 포탑 과충전 약화 로그
- 40분 포탑 자폭 처리
- 미니언 웨이브 자동 생성
- 챔피언/미니언/포탑 자동 교전
- 부드러운 requestAnimationFrame 기반 이동
- 0.5x / 1x / 2x / 4x 관전 속도
- 전투 로그 / 체력 / 골드 / 레벨 표시

주의:
- 아직 실제 LoL 게임 서버나 클라이언트와 연결되는 기능은 아닙니다.
- 현재는 브라우저에서 실행되는 독립적인 시뮬레이션 엔진입니다.
